# MyBusinessCRM — Моя спецтехника

CRM для аренды спецтехники. Статический сайт на русском языке, совместимый с GitHub Pages; сборка не нужна.

## Запуск

Откройте опубликованный сайт GitHub Pages. Главная страница и разделы сохраняют прежнее оформление.

- Без Publishable key заказы работают в прежнем режиме localStorage: только в текущем браузере, без синхронизации между устройствами.
- После настройки `config.js` доступны вход по email/паролю и облачные заказы Supabase с синхронизацией между устройствами.
- Локальные заказы переносятся отдельно, после входа, скачивания резервной копии и подтверждения аккаунта. Исходные данные не удаляются.

**Настройка, соответствие таблицы, проверка RLS и безопасный перенос:** [docs/SUPABASE.md](docs/SUPABASE.md).

В браузере допустим только Publishable key (`sb_publishable_…`). Не добавляйте Secret key, service_role, пароли или строку подключения к базе в файлы сайта.

## Проверки

```sh
npm ci
npx playwright install chromium
npm run check
npm test
```

Тесты изолированы от производственной базы и используют подставные ответы Supabase. Для системного браузера: `CHROMIUM_PATH=/usr/bin/chromium npm test`.

## Техника

Облачный парк техники, журнал ТО/ремонтов/заправок, напоминания, привязка заказов и финансовый результат по машине за период. Перед включением выполните добавочную SQL-миграцию: [пошаговая инструкция](docs/EQUIPMENT.md). Шаблоны Rippa R10, МКСМ-800 и Газель Бизнес ничего не записывают без подтверждения формы.
