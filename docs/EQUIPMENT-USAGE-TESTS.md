# Проверка автоматической наработки — 2 ноября 2026

Рабочая Supabase и реальные клиентские данные не использовались. Проверена исходная схема из миграций main, а не фактическая производственная база. Нужна отдельная проверка её схемы и тестового Supabase перед внедрением.

Команды:

```sh
npm ci --ignore-scripts
npm rebuild @embedded-postgres/linux-x64
npm run check
CHROMIUM_PATH=/usr/bin/chromium npm test
```

`npm test` включает весь существующий набор и новые `tests/equipment-meter.cjs`, `tests/meter-browser.cjs`. Для повторения только нового набора: `CHROMIUM_PATH=/usr/bin/chromium npm run test:meter`. Нужны доступный Chromium и разрешение запуска локальных процессов/порта PostgreSQL. Результаты: PASS. Статической сборки нет; синтаксис проверен `npm run check`, пробелы — `git diff --check`.

Для гонок использовалась временная **PostgreSQL 18.4**, с реальными блокировками при READ COMMITTED, REPEATABLE READ и SERIALIZABLE. Проверены: завершение против изменения часов, повтор статуса, два заказа одной машины, обе очередности активации/завершения, фактическая корректировка против завершения, старый снимок при прямом изменении базы. При старом снимке разрешён безопасный отказ `40001`, затем явно проверен результат повтора. Существующий набор дополнительно проверяет 30 финансовых гонок и безопасность прежних миграций.

Браузерные тесты используют настоящий vendored Supabase SDK и перехват HTTP с вымышленными записями. Это проверка интерфейса, **не end-to-end настоящего Supabase/PostgREST**. Сохранение/восстановление Auth, синхронизация старых разделов, ошибки и localStorage покрыты прежними регрессионными тестами. Новая SQL проверена отдельно в PostgreSQL; живую синхронизацию нового счётчика между реальными устройствами нужно подтвердить в тестовом Supabase.

Не выполнены: миграция на рабочей базе, тест реальных клиентских данных, публикация GitHub Pages, проверка на физических iPhone/Android, тест облачной конфигурации Supabase и её неизвестных сторонних триггеров. Ничего из этого не считается проверенным автоматически. План установки и ручной проверки: [EQUIPMENT-USAGE.md](./EQUIPMENT-USAGE.md).
